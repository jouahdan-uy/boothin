# Boothin Sticker Pack

Final sticker pack for Boothin'.

- Original uploaded stickers are preserved, only renamed sequentially per category.
- 4 additional stickers per category were created as simple hand-drawn/vector-style transparent PNGs to match the supplied themes.
- All assets are PNG with transparent canvas.
- `stickers.json` is ready for the React sticker editor.
